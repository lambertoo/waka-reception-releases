# Waka Reception for Windows

Download the latest MSI from [Releases](https://github.com/lambertoo/waka-reception-releases/releases/latest).

Install the MSI once. Waka checks for newer releases automatically; **Settings → App updates** also lets you check manually. Save your work and choose **Download & restart** when reception can pause briefly.

Release assets contain the Windows MSI, its updater signature, `latest.json`, and `SHA256SUMS`. Waka verifies the update signature before installation.

This repository distributes installers and update metadata only. Application source code is maintained privately. No member records or database files are published here.
